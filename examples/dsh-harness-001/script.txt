Agent 的未来，不只拼大脑多聪明，更拼工作台换错零件后能否收场。
DeepSeek Harness，简称 DSH，瞄准的就是这件事。

模型像大厨，Harness 是后厨，管工具、记忆、权限和任务循环。
所以 DSH 改的是后厨，不是重新训练大脑。

过去的 agent，零件常像焊死在电路板上。
换工具可能要重启，清理漏一点，还会残留连接和状态。
改一处，别处也可能跟着坏。

DSH 主张"一切皆插件"：工具、日志，连 agent 循环都能拆装。
时间可组合性负责拆干净：改动当场附上撤销方法。
卸载时倒序还原，不靠人事后回忆。

空间可组合性负责自动接线：插件只声明需要谁。
依赖到齐就启动，离开就停用，换人就重连。
像乐高会拔插，接口还能自动对准。

关键不是 agent 会不会改自己，而是改坏了能不能安全退回。
这才是 DSH 的深意：未来先要可控地换零件，才谈得上自主改造。
它是在打地基，不是宣布已经会自我进化。

换插件不等于训练模型，更不等于 AGI；发消息、扣款也未必能撤销。
DSH 采用 MIT 许可证开源，仍是开发者预览版，别把地基当大楼。
