# 生产状态与审阅关卡

## 状态流

```text
选题/素材 → 脚本(评审) → 分镜(评审) → 配音 → 信息图 → 数字人 → 音效 → QC → 发布包
```

## 审阅关卡（人在环）

| 关卡 | 产物 | 审什么 |
|---|---|---|
| 脚本 | script.txt / script.json | 事实准确、有专家观点、通俗 |
| 分镜 | scene plan | 7 屏结构、每屏一个中心 |
| 成片 | mp4 | QC 清单全过 |

脚本未确认前，不生成视频。

## 关键决策点

- 脚本方向：先问"独到观点是什么"，再写正文
- 配音：百炼 `qwen-audio-3.0-tts-plus`（效果好）优先，edge-tts 兜底
- 数字人：Live2D 简单版（口型张合）优先，音素级唇形是进阶
- 时长超 75 秒时：TTS 统一提速（每句一致），不动文案
