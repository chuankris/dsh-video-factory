# 成片 QC 验收清单

## 结构

- [ ] 1080×1920、25fps、H.264(yuv420p) + AAC
- [ ] 时长 65~75 秒
- [ ] 有音轨（旁白 + 音效），峰值不削波（≤ -1.5 dBFS）

## 内容

- [ ] 7 屏旁白与定稿脚本逐字一致
- [ ] 有"专家金句"（开头钩子或结尾收口）
- [ ] 事实边界守住（不吹 AGI/自学习，developer preview 说清）

## 字幕

- [ ] 逐句对应配音，无时间重叠
- [ ] 英文词不拆行，标点不单独成行
- [ ] 不越安全区

## 数字人

- [ ] 半身、约 250px 宽、右上角 `W-w-40:165`
- [ ] 不遮标题/图/字幕
- [ ] 旁白结束后隐藏（不遮片尾卡）
- [ ] 口型随配音张合（非静止）

## 动效与音效

- [ ] 任意 3 秒内至少一次可见变化
- [ ] 关键动作点有音效（落件/卡扣/点亮/回滚）

## 合规

- [ ] 烧录"AI 生成"标识（常驻）
