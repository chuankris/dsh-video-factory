# douyin-pack

抖音封面 + 发布文案 + 标签。

## 封面

用 GPT-image（Codex 内置）生成，3:4 竖版（约 1080×1440）。核心要求：

- 主标题 = 视频金句（与开头旁白同频，逐字正确）
- 配色呼应视频（暖白 + 深蓝 + 橙）
- 现代简洁信息图插画风，不写实、无真人、无水印
- 副标题小字点题（如"DeepSeek Harness · 和以前的 agent 差在哪"）

生成后必须 OCR 验证标题逐字正确（错字是封面大忌）。

## 文案模板

```
AI 的竞争，早就不拼谁更聪明了。
拼的是——换错一个零件，能不能安全收场。
<主题一句话>，把 <核心概念> 做成 <一句话比喻>。
一分钟讲清楚：<它和以前的 XX 到底差在哪>。
```

## 标签

```
#AI #DeepSeek #人工智能 #科技科普 #大模型 #Agent
```

## 钩子备选

- 反问钩子："模型再聪明，换错一个零件就崩了，有什么用？"
- 悬念钩子："都在卷模型智商，但真正决定 AI 生死的，是这件事。"

## 原则

- 标题 = 封面金句 = 视频开头第一句旁白，三位一体（提高点击、避免骗点击）
