# 第一集(上)分镜稿 · 待阿光审

《超级个体 与 超级团队》第一集(上),全长 188.43 秒,15 个节拍。
已定稿:节拍 3–4(`scene34.js`,庖丁解牛)、节拍 6–7(`scene67.js`,一百把刀 + 沙漏)。本稿只写剩下 11 个节拍。

## 统一规则

- **视觉母题**:沿用"牛 / 刀 / 缝"这条线。牛是"事",刀是"器"(AI 的手),缝是"判断"(道)。每一段尽量从这三样里取主体,不另起炉灶。
- **材质**:墨黑底 `#050506`,暗金粒子、黄铜金属、宋体字。点云 + 景深 + bloom,和样片同一套 `core.js`。
- **版式**:顶栏、副标签、底部字幕、"AI 生成"标识全部走 `overlay.js` 的 `drawChrome` / `drawSubtitle`。屏上大字用竖排 `vtext`,出处用朱印 `seal`。
- **对齐**:关键动作用 `ptime(句号, '词')` 卡在旁白的字上,下表"卡点"一栏就是这些词。
- **段落边界**:每段首尾 0.5 秒淡入淡出(沿用 `uFade`)。边界一律落在 0.04 秒(一帧)的整数倍,且落在两句之间的静音里,保证拼接后音画不漂。
